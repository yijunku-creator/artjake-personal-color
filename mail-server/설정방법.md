# 메일 발송 + 진단 기록(노션) 설정 — 현재 설정 완료 상태

- Apps Script 프로젝트: "아트제이크 퍼스널컬러 메일" (yijunku@gmail.com 소유), 웹 앱 배포(실행: 나 / 접근: 모든 사용자)
- 앱 연결: personal-color/config.js 의 MAIL_ENDPOINT, MAIL_KEY (KEY는 Code.gs의 KEY와 같아야 함)
- 노션 기록: 아트제이크의 Notion → 아트제이크 스튜디오 → "퍼스널컬러 진단 기록" 데이터베이스
  - 노션 연결 "아트제이크 퍼스널컬러"(API 토큰)가 이 데이터베이스에 접근 권한을 가짐
  - 토큰은 Apps Script [프로젝트 설정 → 스크립트 속성]의 NOTION_TOKEN 에만 저장 (코드·저장소에 넣지 않음)

## 코드를 고쳤을 때
1. Apps Script 편집기에 Code.gs 내용 반영 (KEY는 실제 값으로) → 저장
2. 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포  (URL은 그대로 유지됨)
