# 진단 결과 메일 발송 설정 (무료, 10분)

스튜디오 구글 계정의 Gmail로 고객에게 진단 결과를 보냅니다. 별도 서버나 요금은 없습니다.
설정 전에도 앱은 동작합니다. 그때는 "메일로 받기"를 누르면 아이패드 공유 창이 열리고, 메일 앱을 골라 보내는 방식입니다.

## 1. 스크립트 만들기
1. 스튜디오 구글 계정으로 https://script.google.com 접속 → **새 프로젝트**
2. 기본으로 있는 코드를 지우고 `Code.gs` 내용을 통째로 붙여넣기
3. 맨 위 `KEY` 값을 아무도 모르는 문자열로 바꾸기 (예: `artjake-7f3k2q9`)
4. 저장 (⌘S), 프로젝트 이름은 `아트제이크 퍼스널컬러 메일`

## 2. 권한 승인
1. 위쪽 함수 선택에서 `authorize` 선택 → **실행**
2. 권한 검토 → 스튜디오 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**
   (직접 만든 스크립트라 구글이 확인하지 않았다는 경고입니다)

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니) → **웹 앱**
3. 실행 계정: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/.../exec`)

## 4. 앱에 연결
`personal-color/config.js` 에 붙여넣기:

```js
export const MAIL_ENDPOINT = 'https://script.google.com/macros/s/.../exec';
export const MAIL_KEY = 'artjake-7f3k2q9'; // 1-3에서 정한 KEY와 같은 값
```

## 참고
- 발송 한도: 일반 Gmail 계정 하루 100통, Google Workspace 계정 하루 1,500통
- 고객 메일 주소는 발송에만 쓰이고 앱·스크립트 어디에도 저장되지 않습니다. 보낸 메일은 스튜디오 Gmail의 "보낸편지함"에 남습니다.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
